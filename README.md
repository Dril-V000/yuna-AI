## ✨ What can YUNA do?

- 🎙️ **Voice conversations** — speak to YUNA and hear spoken replies.
- 🎭 **Living characters** — animated Live2D models with expressions and lip-sync.
- 🧠 **Conversation context** — keep character-specific context across chats.
- 🤖 **Your choice of AI** — connect a local model through Ollama or use a supported cloud provider.
- 🛠️ **Useful chat tools** — search the web, open links, and save notes.
- 🎨 **Make it yours** — customize characters, prompts, backgrounds, and compatible Live2D models.

## 🚀 Download & get started

1. Open the **[YUNA Releases page](https://github.com/Dril-V000/yuna-AI/releases/tag/1.3v)**.
2. Expand **Assets** under the latest release.
3. Download the Windows installer/setup file provided there. You do not need to download the source-code ZIP files.
4. Run the installer and follow the setup instructions.
5. Choose how you want YUNA to connect to an AI model.

**New to local AI?** Check the [AI models guide](https://yunaai.online/ai-models/) for model options and the [system requirements](https://yunaai.online/requirements/) before choosing a local model.

## 🌐 Local AI or cloud AI?

YUNA gives you a choice:

- **Local models (Ollama):** run a supported model on your own computer. Performance depends on your hardware and the model you choose.
- **Cloud providers:** connect a supported provider using your own API configuration. An internet connection is required, and provider usage may have its own costs.

The connection method matters: local model conversations can run on your computer, while cloud providers and online features need internet access.
