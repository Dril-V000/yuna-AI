## ✨ What is YUNA?

**YUNA** is a desktop AI companion that runs **entirely on your machine**. She listens to your voice, thinks locally, replies out loud, and her Live2D face moves while she speaks — all without sending a single byte to the cloud.

- 🎙️ **Hands-free voice conversation** — talk naturally, interrupt anytime
- 🎭 **Live2D animated face** — blinks, breathes, lip-syncs, tracks your mouse
- 🧠 **8,000-character rolling memory** — she remembers your conversation
- 🎨 **Custom characters & backgrounds** — Yuna, Haru, or build your own
- 🔒 **100% private** — no telemetry, no cloud, no subscription
- ⚡ **Runs on modest hardware** — no GPU required

## 🚀 Quick Start

### Requirements

| Component | Minimum | Recommended |
|-----------|---------|-------------|
| **OS** | Windows 10 (64-bit) | Windows 11 |
| **CPU** | Intel i5 6th gen / Ryzen 5 1600 | Intel i7 / Ryzen 7 |
| **RAM** | 8 GB | 16 GB |
| **Storage** | 5 GB free | 10 GB free |
| **GPU** | Not required | CUDA-capable (optional) |
| **Ollama** | Required — [download](https://ollama.com/download) | Same |

### Installation

1. **Download** the latest `YUNA-v1.1.2.zip` from [Releases](https://github.com/Code-7/yuna/releases)
2. **Extract** the archive anywhere (e.g., `C:\YUNA\`)
3. **Install [Ollama](https://ollama.com/download)** if you haven't already
4. **Run `YUNA.exe`** — she handles the rest automatically:
   - Activates your license
   - Starts Ollama and picks a model
   - Decrypts the core package
   - Opens the app window

> ⚠️ **First launch needs internet** to download the AI model. After that, YUNA works fully offline.

## 🤖 Supported AI Models

YUNA works with **any Ollama model** out of the box, plus API-based providers:

| Provider | Type | Notes |
|----------|------|-------|
| 🦙 **Ollama** | Local | All models, no API key |
| 🤖 **OpenAI** | Cloud | GPT-4o, GPT-4, GPT-3.5 |
| 🔷 **Anthropic** | Cloud | Claude 3.5, Opus, Haiku |
| 🌊 **DeepSeek** | Cloud | DeepSeek-V3, R1 |
| ♊ **Google Gemini** | Cloud | Gemini 2.0, Gemini Pro |
| ⚡ **Groq** | Cloud | Llama, Mixtral |

**Recommended local models:**
- `qwen2.5:7b` — balanced quality and speed (default)
- `qwen2.5:3b` — fastest, best for weak machines
- `llama3.1:8b` — smarter, needs 16 GB RAM
- `gemma2:9b` — great writing, heavier
