# 🌸 YUNA — Your AI Companion with a Living Face

A Windows desktop AI companion for voice conversations, expressive Live2D characters, and customizable personalities.

- 🎙️ Talk with YUNA using voice and hear spoken replies.
- 🎭 Chat with animated Live2D characters featuring lip-sync and expressions.
- 🧠 Keep character-specific conversation context.
- 🤖 Choose local AI with Ollama or a supported cloud provider.
- 🛠️ Use chat tools to search the web, open links, and save notes.
- 🎨 Customize characters, prompts, backgrounds, and compatible Live2D models.
